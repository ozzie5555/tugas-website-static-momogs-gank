##  Tentang Proyek

Ini adalah project website statis yang dikembangkan oleh Kelompok 9 untuk mempromosikan pariwisata dan identitas budaya kota Semarang, Jawa Tengah. Website ini berfungsi sebagai gerbang digital untuk menemukan *landmark* bersejarah, wisata alam, serta kuliner legendaris seperti Lumpia Semarang dan Wingko Babat.

Proyek ini dibuat untuk memenuhi tugas kurikulum *web development* di SMKN 7 Semarang dengan mengutamakan performa yang cepat dan antarmuka pengguna yang menarik.

---

##  Fitur Utama

*  **Katalog Destinasi**: Informasi lengkap mengenai ikon wisata sejarah (Lawang Sewu, Kota Lama) dan wisata alam (Gunung Ungaran, Brown Canyon).
*  **Panduan Kuliner Khusus**: Halaman khusus yang mengupas tuntas kuliner khas Semarang (Lumpia, Bandeng Presto, Garang Asem, Soto Bangkong, Tahu Gimbal, dll) lengkap dengan rekomendasi dan sejarahnya.
*  **Desain Responsif (Fase Pengembangan)**: Tampilan saat ini sudah dioptimalkan untuk Desktop (1024px+) dan Tablet (768px+). *Catatan: Versi Mobile masih dalam tahap pengembangan.*

---

##  Teknologi yang Digunakan

Proyek ini dibangun murni tanpa *framework* tambahan (*Vanilla*) untuk memaksimalkan kecepatan halaman statis:
* **HTML5** untuk struktur dan semantik web.
* **CSS3** untuk *styling* dan *layout*.
* **JavaScript** untuk fitur interaktif dasar.

---

##  Cara Menjalankan Proyek (Lokal)

Karena ini adalah website HTML statis murni, Anda tidak memerlukan instalasi *backend* atau Node.js.

**1. Clone Repositori**
```bash
git clone [https://github.com/ozzie5555/STATIS-PROJECT.git](https://github.com/ozzie5555/STATIS-PROJECT.git)
cd STATIS-PROJECT

```

**2. Buka di Browser**

* Cara termudah: Cukup klik ganda (buka) file `index.html` di browser Anda.
* Cara terbaik (Developer): Buka folder proyek di VS Code, lalu klik kanan pada `index.html` dan pilih **Open with Live Server**.
