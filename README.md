## Overview

**Momog** is a static website developed by Group 9, designed to promote and preserve the cultural identity of Semarang, Central Java. The platform serves as a digital gateway to discover the city's historical landmarks, natural beauty, and renowned culinary traditions including signature dishes like Lumpia Semarang and Wingko Babat.

The name "Momog" reflects the local community's affectionate term for their beloved city—a metropolitan area steeped in history, architectural heritage, and gastronomic excellence.

## Objectives

- **Cultural Preservation** - Document and promote Semarang's historical and cultural assets
- **Tourism Development** - Provide comprehensive, accessible information for visitors
- **Economic Support** - Highlight local culinary businesses and traditional vendors
- **User Experience** - Deliver fast, responsive browsing for desktop and tablet devices
- **Academic Excellence** - Demonstrate web development skills as part of SMKN 7 Semarang curriculum

## Installation & Usage

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, or Edge)
- No server requirements (pure static HTML)
- Best viewed on desktop or tablet (mobile version in development)

### Local Development

1. Clone the repository
```bash
git clone https://github.com/ozzie5555/STATIS-PROJECT.git
cd STATIS-PROJECT
```

2. Open in browser
```bash
# Simply open index.html in your preferred browser
# Or use a local server for better experience:
python -m http.server 8000
# Navigate to http://localhost:8000
```

3. For development with live reload (optional)
```bash
# Using VS Code Live Server extension
# Right-click on index.html > Open with Live Server
```
